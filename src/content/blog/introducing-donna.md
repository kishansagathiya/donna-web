Donna is an AI personal assistant for founders. Not another chat window. Not another notes app you will never reopen.

The usual split is this: chat products answer questions, and memory products file things away. Neither finishes the job. A real assistant was in the room, remembers your people and projects, and then does the busywork.

That is the loop Donna is built around:

1. **Capture** — speak or type, on iPhone or the web.
2. **Remember** — conversations become structured context, not a graveyard of notes.
3. **Plan** — that context turns into actions.
4. **Act** — agents run in the cloud so you do not have to keep a laptop open.

Memory without action is just another archive. Action without memory is just another command bar. Both halves have to live in the same product.

I am building Donna because I want it and use it every day. This blog is where I will write about that work — memory, voice, agents, and the craft of making an assistant that actually follows through.
